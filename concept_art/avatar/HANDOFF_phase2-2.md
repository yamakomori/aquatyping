## 1. 成果物（DoD）

1. **スクリプト4本**（`scripts/avatar/` に新設。python3＋PIL は利用可能）
   - `prepare-avatar.py` — 原画→128論理グリッド量子化→限定パレットスナップ→クロマキー透過→センタリング→256×256出力。参考実装：`.claude/skills/type-rogue-creature-sprites/scripts/prepare-sprite.py`（4コマ用。1コマ正方形版に改める）
   - `split-avatar-layers.py` — 素体（クリーム→グリーン写像）と outfit-cloth（クリーム画素＋隣接輪郭画素の抽出）への分離。仕様書「レイヤー分離の方針」参照
   - `recolor-avatar.py` — 素体のパレットスワップ（HSL で明度・彩度差を保存）。仕様書のカラーパレット表の4色を生成
   - `validate-avatar.py` — 256×256・RGBA・外周1px完全透明・public/concept_art の SHA256一致を検証。参考：同スキルの `validate-sprite.py`
2. **アセット10ファイル**：`public/avatar/` と `concept_art/avatar/` の両方に同内容で配置
   - `body-moss.png` `body-sky.png` `body-peach.png` `body-night.png` `outfit-cloth.png`
3. **確認用プレビュー**：`tmp/imagegen/avatar/preview-base.png`（4色素体 × ふく有無 の8組み合わせを1枚のグリッドに合成。白背景と暗背景の2段で出力できるとよい）
4. `validate-avatar.py` が全アセットでパスすること

## 2. 処理仕様の詳細

- 量子化：原画(1254×1254) → `Image.resize((128,128), NEAREST)` → パレットスナップ（距離最小。背景 #ff00ff / 輪郭・目のダーク系 / モス3値 / クリーム3値の9色前後に収束させる）
- 透過：スナップ後に #ff00ff → alpha 0
- 配置：**論理ピクセルの再スケール禁止**（ドットが崩れる）。キャラの bbox を求め、水平センタリング・下余白16論理px（12.5%）で平行移動のみ。上余白が12論理px未満になる場合は停止して報告
- 出力：128論理 → NEAREST で2倍 → 256×256 RGBA PNG
- outfit-cloth の輪郭取り込み：クリーム画素に4近傍で隣接する輪郭色画素を含める。頭と襟の境界の輪郭が素体側と二重になるのは許容（同色のため見えない）

## 3. エスカレーション条件（止まる基準）

- [ ] パレットスナップで目・口など顔の特徴が消える／クリームとモスの分離が曖昧で誤写像が広範囲に出る
- [ ] レイヤー分離結果が目視で破綻（ポンチョに大きな穴・素体の欠け）
- [ ] 上余白12論理px未満（帽子スペース不足）
- [ ] 仕様書・本申し送りにない設計判断が必要になり、2回迷った
- 該当したら**作業を止めて報告**。回避策を自力で探さない
