# アバター（きせかえ）アセット仕様

> きせかえブラッシュアップ案件のフェーズ1成果物。
> 設計思想は `avatar.md`、制作パイプラインの原型は
> `.claude/skills/type-rogue-creature-sprites/references/sprite-spec.md` を参照。

## キャラクター設計

- 一体の**中性的な小さな旅人（相棒）**。人型/動物型を選ばせない、丸いシルエット
- **正面〜やや斜め向き・1ポーズ固定**（静止画1コマ。浮遊感は CSS transform で表現）
- 頭身は低く（約2頭身）、頭・胴・手先が明瞭に分かれて見えること（きせかえスロットの視認性のため）
- 表情はおだやか。攻撃的・性別を想起させる記号（まつげ・ひげ等）を入れない
- 配色は限定パレット・フラット塗り＋シンプルな段階シェード。グラデーション・光彩・ドロップシャドウなし

### 採用デザイン（2026-08-08 オーナー選定）

- **案B「ちいさな旅人型」**：丸い頭＋胴＋短い手足が明確に分離した2頭身、太い黒輪郭
- 原画：`tmp/imagegen/avatar/body-source.png`（1254×1254 RGB、マゼンタ #ff00ff クロマキー、約8px論理ドット）
- 論理グリッドは **128×128**（最近傍で縮小して量子化）→ 出力は2倍の 256×256

### レイヤー分離の方針（素体の再構成）

原画はクリーム色のポンチョ（たびのふく）を着た姿。これを2レイヤーに分離する：

- **素体（body-*.png）**：クリーム系画素をモスグリーン系に写像し「全身グリーンの素体」として再構成する
  （ポンチョのシルエットごと体の形とみなす。服レイヤーは常にこの領域を覆うため矛盾しない）
- **たびのふく（outfit-cloth.png）**：クリーム系画素＋それに隣接する輪郭画素のみを抽出した透過レイヤー

この方式により素体と服の位置ズレが原理的に発生しない（同一原画からの分離のため）。

### カラーパレット（からだの色）

素体はモスグリーン3値（影/基本/ハイライト）＋黒輪郭＋目。色変種はパレットスワップで生成：

| item-id | 名前 | 基本色 | 備考 |
|---|---|---|---|
| body-moss | もりいろ | `#88a97a` | 基準体（原画由来） |
| body-sky | そらいろ | `#8eb9cf` | economy.js 既存値 |
| body-peach | ももいろ | `#d99794` | economy.js 既存値 |
| body-night | よぞらいろ | `#6f7fa6` | 新規（深海テーマの濃紺。微調整可） |

影・ハイライトは基準体の3値の明度・彩度差を HSL 空間で保存して各色相へ写像する。輪郭・目の色は全色共通。

## 出力仕様

- 透過PNG、RGBA
- **256 × 256 px**（1コマ・正方形）。生成原画は 1024×1024 → 最近傍補間で縮小
- 画面上では約 96〜128 CSS px で使う。`image-rendering: pixelated`
- キャラ本体はキャンバス中央に配置し、上下左右に約 12% の余白（帽子・持ち物のはみ出し領域）を確保
- 外周 1px は完全透明

## レイヤー構成（重ね順）

すべてのアイテムPNGは**同じ 256×256 キャンバス全体**を持ち、キャラに対する正しい位置に
**制作時点で配置済み**の状態で書き出す（ランタイムは同サイズ画像の絶対配置スタックのみ）。

| z | スロット | 内容 |
|---|---|---|
| 1 | bodyColor | からだ（基準体の色変種。パレットスワップで機械生成） |
| 2 | outfit | ふく（ポンチョ・ケープ・ベスト型を基本。体輪郭と密着させない） |
| 3 | head | あたま（帽子・マスク等） |
| 4 | hand | もちもの（最前面。手先の位置に重ねる） |

### 服（outfit）の制作方針

**全服が outfit-cloth（たびのふく）のシルエット＝マスクを共有**し、マスク内の色・パターンで差別化する
（色替え／しま模様／うろこ模様／計器ドット等）。位置ズレが原理的に発生せず、視覚的一貫性も保たれる。
シルエット差のある服は次バッチ以降の課題とする。

### 帽子・持ち物（head / hand）の制作方針

単体スプライトとして生成→透過→論理グリッド量子化→**基準体のアンカー位置に配置して256×256に焼き込み**。
シルエットの外周は必ず輪郭色（ink系）で囲む（素体と同じ品質基準）。

### 品質基準（オーナー指摘 2026-08-08 反映）

- **シルエット最外周（透明に隣接する可視ピクセル）はすべて輪郭色（ink系）であること**。
  色ドットが黒輪郭の外にはみ出してはならない。validate-avatar.py で機械検証する

## クロマキー・生成手順

- sprite-spec.md に準拠。純色背景（基準体は緑系のため `#ff00ff` を既定）、グラデ・影・光彩なし
- 生成は codex-image（gpt-image-2、1024×1024）→ `prepare-avatar.py` で透過整形＋256×256縮小
- 体色変種は `recolor-avatar.py` でパレットスワップ（AI再生成しない。輪郭の完全一致を保証）
- 透過処理で体色が欠けたら閾値で救済せずクロマキー色を変えて再生成

## ファイル命名・配置

- `public/avatar/<item-id>.png` — item-id は `src/domain/economy.js` の `ITEMS[].id` と一致させる
  - 例：`body-moss.png`, `head-leaf.png`, `outfit-rain.png`, `hand-net.png`
  - `head-none` / `hand-none` はアセットなし（データ側で asset 省略）
- `concept_art/avatar/` に同名ミラー（SHA256一致を `validate-avatar.py` で検証）
- 透過前の原画は `tmp/imagegen/avatar/` に `<item-id>-source.png` として残置

## 検証

- `validate-avatar.py`：寸法 256×256・RGBA・外周透明・public/concept_art の SHA256 一致
- `compose-avatar-preview.mjs`：全アイテム×基準体の組み合わせグリッド画像 → 目視QA
  （位置ズレ・縁残り・スケール不整合・64px縮小時の可読性）
